# 暖语小程序与桌面 EXE 连接说明

## 连接地址（按环境配置，仓库不内置任何局域网 IP）

- 电脑局域网地址：运行 `ipconfig` 查看（Wi-Fi 或热点地址，形如 `172.20.10.x` / `192.168.x.x`）
- 暖语 EXE 小程序网关：`http://<电脑IP>:5005`
- 开发者工具本机回退：`http://127.0.0.1:5005`
- 配置文件：`app.js`（`apiBaseUrl` 留空时由子网自动发现兜底，通常无需手填）

端口 5004 是 ADB 创建的电脑本机回环端口，手机无法访问。小程序只能访问 EXE 新增的 5005 局域网网关。网关只允许 `/api/*`，不会把桌面页面或任意电脑文件暴露到局域网。

## 联调要求

1. 先启动桌面的 `暖语.exe`，等待加载完成。
2. 手机和电脑连接同一个 Wi-Fi，不能使用彼此隔离的访客网络。
3. 微信开发者工具需要关闭合法域名校验；本项目的 `project.private.config.json` 已设置 `urlCheck=false` 和 `useLanDebug=true`。
4. Windows 第一次询问是否允许“暖语”通过防火墙时，选择允许当前网络访问。
5. 如果电脑 WLAN 地址变化，运行 `ipconfig`，把 `app.js` 中的 `apiBaseUrl` 更新为新的 `http://电脑IP:5005`。

## 快速验证

在电脑浏览器打开：

```text
http://<电脑IP>:5005/api/status
```

能看到 JSON 状态表示 EXE 网关正常。如果电脑能打开而手机不能，问题通常是 Windows 防火墙或 Wi-Fi 客户端隔离，不是板卡服务。

## 正式发布限制

局域网 HTTP 只适合开发、演示和同网部署。正式发布到微信并让外网用户使用时，必须部署备案的 HTTPS 域名、在微信公众平台登记 request 合法域名，并增加用户鉴权；不要直接把板卡或电脑端口暴露到公网。
