# 功能设计（第一期）

## 产品定位

小陪是板载语音陪伴设备的轻量远程入口。它不是独立的“全能生活助手”，而是把板端已有的聊天、声音、情绪和专注能力放到手机中，方便用户查看和触发。

## 交互原则

- 温暖、低压力：暖白底色、黄绿渐变、圆角大卡片，信息只有一个主焦点。
- 状态真实：设备离线或接口不可用时显示“等待连接”，不展示虚构数据。
- 操作可追溯：每次远程触发播报、专注或休息，都应由服务端记录用户、设备和时间。
- 隐私优先：对话和情绪仅为陪伴体验服务，不做诊断或风险评分。

## 第二期候选（需先建设后端）

1. 登录与设备绑定：对接现有 `/api/login`，改为小程序 token，加入扫码绑定。
2. 语音输入：调用微信录音接口和 `/api/asr`。
3. 日程：补充日程列表和编辑 API 后再显示提醒卡片。
4. 学习报告：把板端 `daily` 数据整理为按日趋势；不能用推测值补全。

## 明确不做

- 远程看护、老人/儿童/宠物状态、定位、移动控制。
- 未授权的摄像头查看或持续上传。
- 对情绪或人脸结果作医疗、心理或安全判断。
